// SSTI DETECTION METHODOLOGY
1
Find Reflection Points
Look for any place user input appears in the response — profile names, search results, email templates, error messages, custom reports
2
Inject Math Payload
Send detection payload and check if math is evaluated
{{7*7}} or ${7*7} or <%= 7*7 %>
3
Check the Response
If response contains 49 → VULNERABLE. If it shows literal {{7*7}} → safe. If error → dig deeper
4
Fingerprint the Engine
Use {{7*'7'}} — returns 49 in Twig, 7777777 in Jinja2. Different results reveal the engine
{{7*'7'}} → Twig=49 / Jinja2=7777777
5
Document & Report
Screenshot everything, document reproduction steps, generate your bounty report using the DETECT tab
